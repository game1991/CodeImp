## 项目介绍

这是一个使用 Hugo 静态站点生成器和 Stack 主题构建的个人技术博客。项目旨在创建一个简洁、现代且易于维护的博客平台，用于记录技术学习和个人成长。

## 主要特点

- 响应式设计
- 支持中英文双语
- 自定义主题和样式
- 集成评论系统
- SEO 优化

## 技术亮点

1. 使用 Hugo 生成静态站点，提高性能和安全性
2. 自定义 SCSS 样式，实现独特的视觉效果
3. 支持 Markdown 写作，专注于内容创作
4. 通过 GitHub Pages 实现免费托管和持续集成
